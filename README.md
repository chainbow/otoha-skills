# Otoha skills

Official skills for [Otoha AI](https://otohaai.com), published through the Otoha skill market (https://skills.otohaai.com) as system skills.

Each skill is a folder with a `SKILL.md` and its own files. They are written for Otoha's tools and are independent work: no third-party skill text or code is copied in.

| Skill | What it does |
| --- | --- |
| `design` | Posters, interface and web drafts, infographics, diagrams and prototypes as HTML, previewed beside the conversation |
| `slides` | Presentations as HTML slides, one file per slide, presented full screen and exported to PDF; editable PowerPoint through the `pptx` skill |
